# Theme Studio 端到端流程（当前有效版本）

> 当前只保留 **Path B：Web 浏览器流程**。  
> 旧的 Pencil / `.pen` 人工确认流程已经退出主链路，不再作为执行步骤。

---

## 1. 总流程

```text
创建项目
→ AI 对话生成主题
→ Web 预览
→ 用户继续迭代（对话 / 面板）
→ 用户选择要打包的产品
→ 后台截图
→ 标准脚本打包
→ 输出到用户配置目录
```

---

## 2. 阶段说明

### 阶段 1：创建

- 用户打开 Theme Studio
- 新建项目或打开历史项目
- 在对话区描述主题需求

输出：
- 项目上下文建立
- 当前项目进入可编辑状态

---

### 阶段 2：AI 生成与预览

- AI 生成背景图
- 从图片提取主色
- 生成标准色值库
- 将结果注入 HTML 模板
- 在右侧预览中实时展示

输出：
- 当前项目的标准主题结果
  - 颜色变量
  - 背景图 URL
  - HTML 预览状态
  - 项目元数据

> 这里是 AI 工作的核心结束点。  
> 后续是否继续调整，由用户决定。

---

### 阶段 3：迭代

用户可通过两种方式继续修改：

1. **继续对话**
   - 改主题方向
   - 改氛围
   - 让 AI 重新生成或重新配色

2. **打开右侧面板**
   - 手动调整颜色
   - 查看质检信息

规则：
- **谁最后修改，谁生效**

---

### 阶段 4：导出

- 用户点击“打包”
- 选择要导出的产品
- 后台自动执行：
  - Playwright 截图
  - 素材整理
  - `theme_builder.py` 打包

输出：
- 导出批次记录
- 输出目录中的素材包 / 输出包

---

## 3. 当前系统边界

### AI 负责

- 理解用户需求
- 生成背景图
- 生成配色
- 更新 HTML 预览结果

### 产品功能负责

- 项目持久化
- 预览切换
- 面板精修
- 后台截图
- 打包输出

---

## 4. 关于 Pencil / `.pen`

`.pen` 文件现在的角色只有：

- 设计参考
- 模板基准
- 特殊效果的参考来源

它们**不是**当前产品执行流程中的阻塞步骤，不需要：

- 打开 Pencil 人工确认后再继续
- 通过 Pencil MCP 导出作为主截图链路
- 依赖 `.pen` 作为最终渲染器

---

## 5. 当前执行原则

1. **预览源 = HTML**
2. **截图源 = HTML**
3. **打包输入 = 当前项目快照**
4. **导出由用户主动触发**
5. **结果按项目归档，可重新打包**
