# 新建主题流程

## 目的

从用户需求开始，先生成主题背景图，再根据图的主色调创建配色方案。

## 输入

- 主题名称（如：快乐的西双版纳）
- 设计风格（Light-UI / Dark-UI）
- 背景图风格描述

## 输出

- `designs/{nameEn}-bg.png` 主题背景图
- `colors/{nameEn}.json` 配色方案文件

---

## ⚠️ 重要原则：先有图，后有色

**错误流程**（禁止）：
1. ❌ 先凭感觉写配色方案
2. ❌ 再生成背景图

**正确流程**（必须遵守）：
1. ✅ 第一步：生成主题背景图（纯氛围图，无界面元素）
2. ✅ 第二步：分析背景图的主色调、搭配色
3. ✅ 第三步：根据图的主色，按 Light-UI / Dark-UI 规则计算配色方案

**为什么**：主题图是视觉核心，配色必须由图决定，不能脱离图凭空生成。

---

## 流程

### Step 1: 确定模板类型

| 风格 | 模板 | 说明 |
|------|------|------|
| 浅色/明亮背景 | Light-UI | 春节、端午、西瓜等喜庆/清新主题 |
| 深色/暗色背景 | Dark-UI | 夜晚、星空等深邃氛围主题 |

### Step 2: 生成主题背景图

**详细规则**：[../rules/image-generation-rules.md](../rules/image-generation-rules.md)

1. 设计 Prompt：
   - **主体**：场景核心元素（如大象、孔雀、椰林）
   - **氛围**：色调、光线、情绪（如温暖明亮、快乐活泼）
   - **风格**：卡通插画 / 水墨 / 摄影等
   - **约束**："无文字"、"无界面元素"、"纯氛围图"

2. 调用 MiniMax API 生成：
```bash
source .env
# 输出到 designs/{nameEn}-bg.png，16:9 比例
```

3. 生成后分析图片：
   - 主色调（色相角度）
   - 搭配色（辅助色、点缀色）
   - 整体氛围

### Step 3: 根据背景图生成配色方案

**创建文件**：`colors/{nameEn}.json`

**Light-UI 色调规则（从图提取）**：
- **primary** = 背景图中最鲜艳的主题色（色相不变，亮度 45-60%）
- **primaryHover** = primary 增加亮度（亮度 +15%，亮度 60-75%）
- **alterColor** = primary 降饱和+降亮度（亮度 -15%，降饱和 20%）
- **alterColorHoverOn** = primaryHover 增加亮度（亮度 +15%）
- **gradient** start → end = primary → 搭配色

**Dark-UI 色调规则**：
```
Primary = 背景图主色调
Primary-hover = Primary + 26°
Header-font = Primary + 22°
```

**Light-UI 模板**：

## 配色计算公式

### Light-UI 透明度计算（白色混合法）

```javascript
primaryOpacity10 = blendWhite(primary, 0.1)  // 10% 透明度
primaryOpacity20 = blendWhite(primary, 0.2)  // 20% 透明度
primaryOpacity30 = blendWhite(primary, 0.3)  // 30% 透明度
```

### Light-UI Alter 颜色计算

```javascript
alterColor = desaturate(darken(primary, 15%), 20%)
alterColorHoverOn = lighten(primaryHover, 15%)
```

### Dark-UI Alter 颜色计算

```javascript
alterColor = darken(primary, 15-20%)
alterColorHoverOn = darken(primaryHover, 15%)
```

## 验证清单

- [ ] `designs/{nameEn}-bg.png` 已生成（纯氛围图，无界面元素）
- [ ] 背景图主色调已提取
- [ ] `colors/{nameEn}.json` 已创建
- [ ] `templateType` 字段正确（light-ui 或 dark-ui）
- [ ] `nameEn` 字段存在且唯一
- [ ] `alterColor` 和 `alterColorHoverOn` 已计算
- [ ] 色调计算正确（Light-UI 亮度规则 / Dark-UI 色调偏移）
- [ ] 配色基于背景图，不是凭空生成
