# 设计确认流程

## 目的

在 Pencil 中确认主题设计，替换颜色变量和背景图。

## 输入

- `colors/{nameEn}.json` 配色方案
- `designs/{nameEn}-bg.png` 背景图
- 模板文件（Light-UI-模板.pen / Dark-UI-模板.pen）

## 输出

- `designs/Topic-{主题名}-{timestamp}.pen` 设计文件

---

## 流程

### Step 1: 复制模板

根据 templateType 选择对应模板：
```bash
# Light-UI 模板
cp "designs/sources/Light-UI-模板.pen" "designs/Topic-{主题名}-{timestamp}.pen"

# Dark-UI 模板
cp "designs/sources/Dark-UI-模板.pen" "designs/Topic-{主题名}-{timestamp}.pen"
```

### Step 2: 用脚本自动替换（⭐ 标准做法）

**禁止手动替换！使用自动化脚本**：
```bash
python3 scripts/update-pen-theme.py {nameEn}
```

**脚本自动完成以下 6 项任务**：
1. 替换框架名称（【清明节】→ 新主题名，跳过"勿删除"框架）
2. 更新所有 color 类型 variables（primary-color 等）
3. **更新 text content 中的硬编码色值**（如 `$primary-color\n#2C615C` → `$primary-color\n#F5C542`）
4. 更新渐变组件（只更新 RWYIx/6U9v0 节点，不碰其他渐变）
5. 替换登录页背景图（使用绝对路径，匹配所有旧登录图路径模式）
6. 替换页眉/工作台中的背景图

**脚本的关键设计**：
- 使用硬编码的模板默认值构建色值映射（不读 pen 文件，避免 pen 已被修改导致映射失效）
- 背景图使用绝对路径（Pencil 需要绝对路径才能正确加载）
- 精确匹配渐变节点 ID（RWYIx 和 6U9v0），不误伤其他渐变

### Step 3: 打开 Pencil 确认

```bash
open -a Pencil "designs/Topic-{主题名}-{timestamp}.pen"
```

### Step 4: 验证无残留红色（脚本已自动处理）

```bash
# 可选验证
grep -E "#a7160b|#94170e|#C41B00|#fdd0a3" "designs/Topic-*.pen" | wc -l
# 结果应为 0 或仅保留原始模板的红色
```

### Step 5: 🚧 用户确认门禁（必须等待明确指令）

**⚠️ 此步骤为阻塞点，必须等待用户明确说"可以"、"继续"、"没问题"才能进入下一步。**

打开 Pencil 让用户确认完整设计效果：

```bash
open -a Pencil "designs/Topic-{主题名}-{timestamp}.pen"
```

**展示内容**：
- 登录页设计效果（新背景图 + 新配色）
- 页眉设计效果
- 工作台设计效果

**禁止行为**：
- ❌ 不要自动进入导出流程
- ❌ 不要自动执行 03-导出素材流程
- ❌ 不要在 Pencil 打开后立即继续后续步骤

**等待用户明确确认后，才能进入**：
- ✅ [03-导出素材流程.md](03-导出素材流程.md)
