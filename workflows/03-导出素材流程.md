# 导出素材流程

## 目的

从 Pencil 导出设计素材，并裁剪到正确尺寸。

## 输入

- `designs/Topic-{主题名}-{timestamp}.pen` 设计文件
- `colors/{nameEn}.json` 配色方案

## 输出

- `output/{date}-{nameEn}/素材包/` 下的切图文件

---

## 流程

### Step 1: 检查 Pencil MCP 连接

```javascript
pencil_get_editor_state({ include_schema: false })
```

**如果返回 `Not connected`**：
1. 确保 Pencil 桌面应用正在运行
2. 在 Pencil 中：File → MCP Server → Connect
3. 重试

### Step 2: 创建输出目录

```bash
mkdir -p "output/{date}-{nameEn}/素材包"
mkdir -p "output/{date}-{nameEn}/素材包/login_bg"
```

### Step 3: 导出页眉背景节点和工作台整体（PNG，scale=1）

```javascript
// 导出所有页眉背景节点 + 工作台整体（必须用 scale: 1）
pencil_export_nodes({
  filePath: "designs/Topic-{主题名}-{timestamp}.pen",
  nodeIds: ["A7bgM", "TdfhH", "C0kVM", "Nk9d0", "jTA4O", "dKOHu"],
  outputDir: "output/{date}-{nameEn}/素材包",
  format: "png",
  scale: 1    // ⭐ 必须是 1！默认 scale=2 会导致尺寸错误
})
```

### Step 4: 导出登录页背景和整体截图（JPG，scale=1）

```javascript
pencil_export_nodes({
  filePath: "designs/Topic-{主题名}-{timestamp}.pen",
  nodeIds: ["LiN3g", "nXv3Y"],
  outputDir: "output/{date}-{nameEn}/素材包",
  format: "jpeg",
  scale: 1    // ⭐ 必须是 1！
})
```

### Step 5: 裁剪并整理文件（ImageMagick convert）

```bash
cd "output/{date}-{nameEn}/素材包"

# === 登录包图片 ===
# bg-login.jpg（保持 2215×1080）
cp LiN3g.jpeg bg-login.jpg

# background.png（2215×1080 → 1920×1080，居中裁剪左右各 147.5px）
convert bg-login.jpg -crop 1920x1080+147+0 +repage background.png

# login_thumb（nXv3Y → 960×540）
convert nXv3Y.jpeg -resize 960x540\! login_thumb.jpg

# thumb-1 和 thumb-2（从 bg-login.jpg 裁剪 800×390）
convert bg-login.jpg -crop 800x390+0+345 +repage login-bg-thumb1.jpg
convert bg-login.jpg -crop 800x390+800+345 +repage login-bg-thumb2.jpg
mv login-bg-thumb1.jpg login_bg/
mv login-bg-thumb2.jpg login_bg/

# === 页眉背景（直接复制，无需裁剪）===
cp A7bgM.png header_tlayout_frame_bg.png
cp A7bgM.png header_simple_frame_bg.png
cp TdfhH.png header_complex_frame_bg.png
cp C0kVM.png header_menu_frame_bg.png
cp jTA4O.png header-sideheader.png
cp jTA4O.png header_single_menu_frame_bg.png

# header-banner.png（Nk9d0 导出为 2560×536，需裁剪 y+30 得到 480px）
convert Nk9d0.png -crop 2560x480+0+30 +repage header-banner.png

# === MK 主题缩略图（从 dKOHu 工作台导出）===
convert dKOHu.png -resize 1440x800\! desktop.png
convert dKOHu.png -resize 1600x572\! layout-banner.jpg
convert dKOHu.png -resize 1600x572\! fullscreen-sideheader.jpg
convert dKOHu.png -resize 1600x572\! fullscreen-sidenav.jpg
convert dKOHu.png -resize 1600x572\! center-sidenav.jpg

# 清理原始导出文件
rm -f LiN3g.jpeg nXv3Y.jpeg A7bgM.png TdfhH.png C0kVM.png Nk9d0.png jTA4O.png dKOHu.png login-bg-thumb1.jpg login-bg-thumb2.jpg
```

### Step 6: 🚧 验证门禁（⭐ 必须通过才进入下一流程）

**⚠️ 如果以下任何一项失败，不能继续，必须修复后重新验证。**

| 验证项 | 命令 | 要求 |
|--------|------|------|
| 素材文件完整性 | 见下方 check 脚本 | 所有 17 个文件必须存在 |
| 文件尺寸匹配 | 见下方 check 脚本 | 每个文件尺寸必须完全匹配 |

```bash
cd "output/{date}-{主题名}/素材包"
python3 -c "
# 验证代码：检查17个文件是否存在且尺寸正确
from PIL import Image
import os

files = {
    'bg-login.jpg': (2215, 1080),
    'background.png': (1920, 1080),
    'login_thumb.jpg': (960, 540),
    'login_bg/thumb-1.jpg': (800, 390),
    'login_bg/thumb-2.jpg': (800, 390),
    'header-banner.png': (2560, 480),
    'header_tlayout_frame_bg.png': (1920, 60),
    'header_simple_frame_bg.png': (1920, 60),
    'header_complex_frame_bg.png': (1920, 90),
    'header_menu_frame_bg.png': (1920, 130),
    'header-sideheader.png': (200, 900),
    'header_single_menu_frame_bg.png': (200, 900),
    'desktop.png': (1440, 800),
    'layout-banner.jpg': (1600, 572),
    'fullscreen-sideheader.jpg': (1600, 572),
    'fullscreen-sidenav.jpg': (1600, 572),
    'center-sidenav.jpg': (1600, 572),
}

all_ok = True
missing = []
for fname, (ew, eh) in files.items():
    if not os.path.exists(fname):
        missing.append(fname); all_ok = False; continue
    img = Image.open(fname)
    w, h = img.size
    if w != ew or h != eh:
        print(f'❌ {fname}: {w}x{h} (expect {ew}x{eh})')
        all_ok = False
    else:
        print(f'✅ {fname}: {w}x{h}')

if not all_ok:
    print(f'\\n⛔ 验证失败: {len(missing)} 个缺失')
    for m in missing: print(f'  缺失: {m}')
    exit(1)
else:
    print(f'\\n✅ 全部通过: {len(files)} 个文件')
"
```

**验证结果判断**：
- ✅ 全部通过 → 进入 [04-批量打包流程.md](04-批量打包流程.md)
- ❌ 任何失败 → **STOP**，找到缺失/尺寸不匹配的文件，修复后重新验证
