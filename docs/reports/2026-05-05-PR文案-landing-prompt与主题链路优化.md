# PR 文案

## 标题

feat: 完善 landing prompt 配置、主题主色链路与积分说明能力

## 描述

### 背景

本次提交主要围绕 Theme Studio 最近四天的持续迭代展开，重点补齐首页快捷入口、主图生成主题的主色控制、积分说明配置化，以及相关 UI/测试保障。

### 主要改动

1. 首页快捷指令可配置化
- 修复 landing prompt 点击链路问题。
- 首页快捷指令从固定文案升级为可配置结构，支持 `label`、`prompt`、`primaryHint`。
- 新增独立管理页，支持直接维护首页 8 条快捷指令。

2. 主图生成主题的颜色链路增强
- 首页卡片、聊天输入和主图应用流程之间新增 `primaryHint` 透传。
- `apply_selected_theme` 调用携带主题色提示和语义文本。
- 新增企业安全色映射、企业主色库与节日颜色规则，提升主题色稳定性。

3. 积分说明与后台配置打通
- 服务端 `security_config` 新增 `credits_tooltip_content`。
- 积分接口支持返回 tooltip 文案。
- landing 页新增积分说明 tooltip 交互与展示逻辑。

4. 导出与接口层细节优化
- 导出压缩包命名调整为 `YYYYMMDD-快照名.zip`。
- 部分前端请求改为统一走 `apiFetch`。
- 相关导出、会话、项目工作流模块同步收敛。

5. UI 打磨与测试补强
- landing 页、聊天输入区、配置页、积分提示层等样式持续优化。
- 新增和补充多项单元测试，覆盖 landing prompt 管理、主色映射、积分 tooltip、导出命名、主题状态恢复等契约。

### 验证情况

- 已执行：`npm test -- --run`
- 结果：本次新增相关测试有通过，但仓库当前仍存在一批既有失败用例，以及沙箱环境下 `127.0.0.1` 监听受限导致的失败，本次未一并清理。
