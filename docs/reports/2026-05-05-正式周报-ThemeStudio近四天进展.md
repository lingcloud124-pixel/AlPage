# Theme Studio 近四天进展周报

时间范围：2026-05-01 至 2026-05-05

## 一、本周完成

### 1. 首页快捷入口能力持续完善

- 修复首页快捷指令点击后的聊天触发链路问题，确保快捷入口可以稳定进入生成流程。
- 将首页快捷指令从固定写死文案升级为可配置结构，支持维护标题文案、长 Prompt 和固定主题色提示。
- 新增独立快捷指令配置页，支持直接管理首页 8 条指令，降低后续运营和调优成本。

### 2. 主图生成主题的主色控制能力增强

- 在首页选图、聊天输入和主图应用之间补充 `primaryHint` 透传能力。
- 增强主题生成调用参数，支持同时传递主题色提示和语义来源文本。
- 新增企业安全色映射、企业主色库和节日颜色规则，推动“语义 -> 稳定主色”的能力落地。
- 目标是降低生成主题时的颜色漂移，提升企业主题和节日主题的一致性。

### 3. 积分说明完成配置化打通

- 服务端安全配置表新增积分说明字段，支持持久化维护。
- 前端 landing 页新增积分说明 tooltip，支持点击和悬停展示。
- 积分规则说明由后端配置统一下发，减少前端硬编码。

### 4. 导出和接口层体验优化

- 导出压缩包命名规范化，改为按日期前缀输出，更适合正式归档。
- 前端认证和部分接口请求开始统一走 `apiFetch`，增强请求层一致性。
- 导出、会话、项目状态等周边模块做了同步收口，整体稳定性有所增强。

### 5. 界面与交互细节打磨

- 持续优化 landing 页、聊天输入区、按钮、积分说明层、独立配置页等关键界面样式。
- 抽离桌面模板行为逻辑，降低模板加载代码的耦合度，便于后续维护。
