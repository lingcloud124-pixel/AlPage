## 术语口径

为避免命名漂移，本目录统一使用以下术语：

- **Theme Studio**：面向用户的 Web 工作台名称
- **主题自动化 / Topic Automation**：整个项目/仓库名称
- **主题包**：最终导出的多版本 zip 产物
- **素材包**：打包前的截图与中间资源集合
