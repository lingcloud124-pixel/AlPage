# 批量打包流程

> 重要：后续若重构导出链路、截图流程或目录结构，必须先阅读并保持  
> `docs/internal/IMPORTANT-EXPORT-INVARIANTS.md` 中的基线约束不丢失。

## 目的

使用 `theme_builder.py` 生成所有版本的 主题+登录 包。

## 输入

- `output/{date}-{主题名}/素材包/` 切图文件
- `assets/references/samples/主题样例包/` 模板 zip 文件

## 输出

- `output/{date}-{主题名}/输出包/*.zip` 9个主题包（含登录变体）

---

## 流程

### Step 1: 创建 YAML 配置

在素材包目录下创建 `theme-build-request.yaml`：

```bash
cd "output/{date}-{主题名}/素材包"
```

```yaml
title: "{中文主题名}"
subtitle: "副标题"
buttonText: "立即进入"
themeColor: "#主色HEX"
products:
  - mk
  - ekp_v14_16
  - ekp_v17
images:
  headerBanner: "../素材包/header-banner.png"
  headerClassic: "../素材包/header_complex_frame_bg.png"
  headerSimple: "../素材包/header_tlayout_frame_bg.png"
  headerTabs: "../素材包/header_tlayout_frame_bg.png"
  headerIcon: "../素材包/header_tlayout_frame_bg.png"
  headerSideheader: "../素材包/header-sideheader.png"
  loginBackground: "../素材包/bg-login.jpg"
  loginLogo: ""
```

**products 说明**：

| product | 生成包 | 说明 |
|---------|--------|------|
| `mk` | 主题-MK + 登录-MK | 现代版本 |
| `ekp_v14_16` | 主题-V14〜V16 + 登录-V14〜V16 + 登录-V14 + 登录-V15 + 登录-V16 | EKP V14〜V16（含变体） |
| `ekp_v17` | 主题-V17 + 登录-V17 | EKP V17 |

### Step 2: 🚧 验证素材完整性

```bash
cd "output/{date}-{主题名}/素材包" && ls -la header-banner.png bg-login.jpg header-sideheader.png header_tlayout_frame_bg.png header_complex_frame_bg.png header_simple_frame_bg.png desktop.png
```

### Step 3: 执行打包

```bash
cd "output/{date}-{主题名}/素材包"
python3 "/绝对路径/theme_builder.py" --config theme-build-request.yaml --output "../输出包"
```

### Step 4: 🚧 验证门禁（⭐ 必须通过）

```bash
cd "output/{date}-{主题名}/输出包"
# 生成 9 个 zip（mk theme+login, v14-16 theme+login variants, v17 theme+login）
ls *.zip | wc -l
# 应该输出 9
```

**验证颜色注入**：
```bash
unzip -o -q '主题-V14〜V16-*.zip' -d /tmp/verify
find /tmp/verify -name "*.css" -path "*/style/*" -exec cat {} \; | grep -oE '#[0-9a-fA-F]{6}' | sort | uniq -c | sort -rn | head -3
# 主色（如 #F5C542）应该是出现次数最多的
rm -rf /tmp/verify
```

**结果判断**：
- ✅ 9 个 zip + 主色是出现最多的颜色 → 打包完成
- ❌ 任何失败 → **STOP**，修复后重新打包

## 已知限制

### `theme_builder.py` 的 `find_first_subdir` 修复

`find_first_subdir` 默认返回字母序第一个子目录。当前支持版本的登录包都按现有提取与重打包流程处理；旧的 V12/V13 兼容逻辑已不再作为现行支持范围。

### 登录包模板映射

`theme_builder.py` 内部使用 LOGIN_VARIANTS 字典映射：
- `ekp_v14_16` → [`登录-V14〜V16`, `登录-V14`, `登录-V15`, `登录-V16`]

### 版本命名

生成的包名格式通过 VERSION_LABELS 字典控制：
```python
VERSION_LABELS = {
    'mk': 'MK',
    'ekp_v14_16': 'V14〜V16',
    'ekp_v17': 'V17'
}
```
