# 导出素材流程（当前有效版本）

> 当前导出素材流程基于 **HTML 预览 + Playwright 截图**。  
> 旧的 Pencil MCP 节点导出流程已不再作为主链路。

---

## 1. 目的

把当前项目的预览结果转换为后续打包所需的标准素材。

---

## 2. 输入

- 当前项目快照
  - 颜色变量
  - 背景图
  - 模板类型
  - 项目元数据
- 用户所选产品
- HTML 模板渲染结果

---

## 3. 输出

- 当前导出批次的素材文件
- 供 `theme_builder.py` 使用的打包输入

---

## 4. 流程

### Step 1：创建导出批次

系统根据：

- 当前项目
- 用户勾选的产品
- 用户配置的导出根目录

创建一个新的导出批次目录。

---

### Step 2：后台截图

系统通过 Playwright 对 HTML 预览进行截图：

- 登录页相关素材
- 主页相关素材
- 页眉 / banner / sideheader 等目标素材

核心原则：

1. **截图源 = HTML 预览**
2. **截图使用当前项目快照，不是模板原始图**
3. **截图过程对用户透明，在后台执行**

---

### Step 3：整理素材

截图完成后，系统整理输出目录：

- 统一命名
- 统一尺寸
- 统一目录结构

为后续打包准备标准输入。

---

### Step 4：调用标准脚本打包

系统调用：

- `theme_builder.py`

把当前批次素材打成对应产品包。

---

## 5. 当前导出门禁

导出前必须满足：

- 当前项目存在
- 用户已选择至少一个产品
- 已配置导出根目录
- 当前预览结果已确认可导出

---

## 6. 关于旧 Pencil 导出流程

以下内容都已退出主链路：

- 打开 Pencil
- 检查 Pencil MCP 连接
- 通过节点 ID 从 `.pen` 直接导图
- 把 `.pen` 当成最终截图源

现在 `.pen` 的角色只剩：

- 模板参考
- 视觉基准参考

---
