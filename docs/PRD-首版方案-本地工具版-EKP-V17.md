# Theme Studio 首版方案（本地工具版 / EKP-V17）

> 版本：v1.0
> 形态：macOS 本地工具
> 范围：解压即可使用 / 用户自行配置模型 / 首版仅支持 EKP-V17 导出

---

## 一、产品定位

本地工具版是一个面向交付场景的主题生成工具。

用户在本机启动应用后，通过对话生成主题、查看预览、保存项目，并最终导出 EKP-V17 主题包。

一句话定义：

**一个面向本地交付场景的 EKP-V17 主题生成与导出工具。**

---

## 二、目标用户

适用用户：

- 需要在本地环境中完成主题生成与导出的客户
- 对数据本地可控有要求的客户
- 不希望依赖在线服务的交付场景
- 企业内网或私有环境用户

用户特征：

- 不懂代码
- 可以理解基础模型配置
- 希望直接拿到可导出的主题结果

---

## 三、首版目标

首版目标不是覆盖全部 OA 版本，而是完成一个稳定闭环：

1. 用户拿到包后可以启动
2. 用户可以完成模型配置
3. 用户可以通过默认对话态开始创作
4. 用户可以生成并预览主题
5. 用户可以保存项目
6. 用户可以导出 EKP-V17

---

## 四、首版范围

### 4.1 支持范围

首版支持：

- macOS
- 本地启动
- 用户自行配置聊天模型与图片模型
- 默认对话态创作
- 自动项目创建
- 项目保存
- EKP-V17 导出

### 4.2 不支持范围

首版不支持：

- Windows
- 在线服务
- 用户登录体系
- 多人协作
- 云同步
- MK
- EKP-V12
- EKP-V13
- EKP-V13.5
- EKP-V14
- EKP-V15
- EKP-V16
- 多版本批量导出

---

## 五、首版核心能力

### 5.1 模型配置

用户可配置：

- 聊天模型 Endpoint / API Key / Model
- 图片模型 Endpoint / API Key / Model

要求：

- 支持保存配置
- 支持测试连接
- 错误提示对普通用户可理解

### 5.2 默认对话态

用户启动并完成配置后，直接进入默认对话态，而不是要求先手动新建项目。

默认态要求：

- 有欢迎语
- 有推荐主题方向或推荐问题
- 可直接输入需求
- 第一轮对话开始后自动创建项目

### 5.3 实时预览

支持：

- 登录页预览
- 主页预览
- 配色调整
- 继续对话迭代

### 5.4 项目管理

支持：

- 自动创建项目
- 自动保存项目
- 查看历史项目
- 继续编辑项目

### 5.5 EKP-V17 导出

支持将当前主题导出为 EKP-V17。

这是本地工具版首版的核心闭环能力。

---

## 六、用户流程

### 6.1 第一次使用

1. 用户下载并解压应用包
2. 启动应用
3. 进入设置
4. 配置聊天模型
5. 配置图片模型
6. 测试连接
7. 保存设置
8. 返回主界面
9. 进入默认对话态
10. 输入一句需求开始生成

### 6.2 生成与编辑

1. 输入需求
2. 系统生成背景图与配色
3. 自动创建当前项目
4. 显示预览
5. 用户继续微调

### 6.3 导出

1. 点击导出
2. 当前版本仅可选择 EKP-V17
3. 选择导出目录
4. 开始导出
5. 显示成功提示与输出目录

---

## 七、初体验要求

首版初体验必须保证：

- 用户不需要理解开发环境
- 用户不需要先学习复杂流程
- 用户可以快速进入可对话状态
- 用户能理解当前版本只支持 EKP-V17
- 用户能在一次流程内完成从生成到导出

需要重点避免：

- 启动后不知道下一步做什么
- 配置失败时只有技术错误
- 默认态太空，用户无从下手
- 导出时才发现当前版本限制

---

## 八、验收标准

首版本地工具版完成的标准：

1. macOS 用户可以启动应用
2. 用户可以独立完成模型配置
3. 用户可以直接从默认对话态开始创作
4. 用户可以看到预览结果
5. 用户可以保存并继续编辑项目
6. 用户可以导出 EKP-V17
7. 用户可以找到导出结果

---
