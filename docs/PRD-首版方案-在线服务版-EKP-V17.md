# Theme Studio 首版方案（在线服务版 / EKP-V17）

> 版本：v1.0
> 形态：在线服务
> 范围：复用现有客户系统登录 / 我们提供模型和服务 / 首版仅支持 EKP-V17 导出

---

## 一、产品定位

在线服务版不是一个让用户自行配置模型的工具，而是一个由我们统一提供模型与服务能力的在线创作平台。

用户登录后，直接通过对话生成主题、调整预览并导出 EKP-V17。

一句话定义：

**一个挂接在现有客户体系中的 EKP-V17 在线主题生成与导出服务。**

---

## 二、目标用户

适用用户：

- 已经在使用现有客户系统的用户
- 希望直接在线创作主题的用户
- 不希望配置模型、环境、依赖的用户

用户特征：

- 已具备现有系统账号
- 期望打开即用
- 更关注生成结果与导出效率，而不是底层模型配置

---

## 三、首版目标

在线服务版首版目标：

1. 用户通过现有客户系统登录进入 Theme Studio
2. 用户无需配置模型
3. 用户直接进入默认对话态
4. 用户可以完成主题生成、预览、保存
5. 用户可以导出 EKP-V17

---

## 四、首版范围

### 4.1 支持范围

首版支持：

- 复用现有客户系统登录
- 默认对话态创作
- 我们统一提供聊天模型与图片模型
- 项目保存
- EKP-V17 导出

### 4.2 不支持范围

首版不支持：

- 用户自定义模型配置
- 独立注册体系
- MK
- EKP-V12
- EKP-V13
- EKP-V13.5
- EKP-V14
- EKP-V15
- EKP-V16
- 多版本批量导出
- 团队协作高级权限
- 平台级运营功能

---

## 五、首版核心能力

### 5.1 登录与身份

要求：

- 复用现有客户系统登录能力
- 用户无须重复注册 Theme Studio 账号
- Theme Studio 可以识别当前用户身份
- 项目与导出记录归属到当前用户

### 5.2 默认对话态

用户登录后应直接进入默认对话态，而不是进入空白后台。

默认态要求：

- 有欢迎语
- 有推荐主题方向或示例问题
- 可直接开始输入需求
- 第一轮对话开始后自动创建项目

### 5.3 统一模型服务

由我们提供：

- 聊天模型服务
- 图片模型服务
- 生成流程调度

普通用户不需要看到：

- endpoint
- API Key
- model name
- 连接测试

### 5.4 项目与预览

支持：

- 自动项目创建
- 自动保存
- 登录页预览
- 主页预览
- 颜色调整
- 继续对话迭代

### 5.5 EKP-V17 导出

支持用户在在线服务中完成 EKP-V17 导出。

这是在线服务版首版的产品闭环。

---

## 六、用户流程

### 6.1 登录进入

1. 用户从现有客户系统进入 Theme Studio
2. 已登录状态下直接进入工作区
3. 看到默认对话态

### 6.2 生成与编辑

1. 输入主题需求
2. 系统生成背景图与配色
3. 自动创建当前项目
4. 展示预览
5. 用户继续调整与迭代

### 6.3 导出

1. 点击导出
2. 当前版本仅可选择 EKP-V17
3. 开始导出
4. 系统完成服务端处理
5. 用户获取导出结果或下载入口

---

## 七、初体验要求

在线服务版的初体验标准比本地工具版更高。

必须满足：

- 用户登录后即可开始，不需要再配置模型
- 首屏应引导用户直接开始创作
- 第一轮生成结果要尽快可见
- 当前版本仅支持 EKP-V17 的边界必须清晰
- 导出结果要易于获取

需要重点避免：

- 登录后进入空白页面
- 用户不知道 Theme Studio 能做什么
- 用户误以为支持全部 EKP 版本
- 导出失败没有清晰说明

---

## 八、验收标准

首版在线服务版完成的标准：

1. 用户可通过现有客户系统进入
2. 登录后可直接进入默认对话态
3. 用户无需配置模型即可开始创作
4. 用户可完成主题生成与预览
5. 用户项目可保存
6. 用户可导出 EKP-V17
7. 用户可获取导出结果

---

## 九、后续演进

后续版本再评估：

- EKP 其他版本支持
